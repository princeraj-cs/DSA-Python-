# DSA Roadmap

### Week 1: Python Refresher

- Python syntax, variables, operators, and control flow
- Functions, recursion, and scope
- Built-in data types: strings, tuples, lists, sets, and dictionaries
- List and dictionary comprehensions
- Classes, objects, and basic object-oriented programming
- Reading input, formatting output, and writing reusable code

### Week 2: Complexity, Sorting, and Searching

- Algorithms and problem-solving approach
- Time and space complexity
- Big O, Big Omega, and Big Theta notations
- Best-case, average-case, and worst-case analysis
- Linear search and binary search
- Bubble sort, selection sort, and insertion sort
- Merge sort, quick sort, and counting sort
- Stability and in-place sorting

### Week 3: Linear Data Structures and Hashing

- Arrays and dynamic arrays
- Python lists and common list operations
- Linked lists: singly, doubly, and circular
- Stacks and stack applications
- Queues, circular queues, and deques
- Hash tables, hash functions, and collision handling
- Sets and dictionaries
- Two-pointer and sliding-window techniques

### Week 4: Graph Fundamentals

- Graph terminology and representations
- Adjacency matrix and adjacency list
- Directed, undirected, weighted, and unweighted graphs
- Breadth-first search (BFS)
- Depth-first search (DFS)
- Connected components
- Cycle detection
- Topological sorting

### Week 5: Advanced Graph Algorithms

- Shortest paths in unweighted graphs
- Dijkstra's algorithm
- Bellman-Ford algorithm
- Floyd-Warshall algorithm
- Minimum spanning trees
- Prim's algorithm
- Kruskal's algorithm
- Strongly connected components

### Week 6: Union-Find, Heaps, and Search Trees

- Union-Find / Disjoint Set Union (DSU)
- Path compression and union by rank
- Priority queues
- Binary heaps and heap operations
- Heap sort
- Binary search tree (BST)
- BST insertion, deletion, and traversal
- BST complexity and practical use cases

### Week 7: Balanced Trees and Greedy Algorithms

- Problems with unbalanced search trees
- AVL trees and tree rotations
- Red-black tree concepts
- Greedy strategy and proof intuition
- Activity selection
- Fractional knapsack
- Job sequencing
- Huffman coding

### Week 8: Divide and Conquer

- Divide-and-conquer strategy
- Recurrence relations
- Master theorem
- Merge sort and quick sort analysis
- Binary search
- Inversion counting
- Closest pair of points
- Strassen's matrix multiplication

### Week 9: Dynamic Programming

- Overlapping subproblems and optimal substructure
- Memoization and tabulation
- State definition and transition design
- 0/1 knapsack
- Coin change
- Longest common subsequence
- Longest increasing subsequence
- Matrix chain multiplication
- Shortest paths using dynamic programming

### Week 10: String and Pattern Matching

- String representation and string operations
- Naive pattern matching
- Rabin-Karp algorithm
- Knuth-Morris-Pratt (KMP) algorithm
- Z algorithm
- Trie data structure
- Prefixes, suffixes, and substrings
- Applications of pattern matching

### Week 11: Advanced Algorithmic Paradigms

- Flow networks and residual graphs
- Ford-Fulkerson algorithm
- Edmonds-Karp algorithm
- Maximum flow and minimum cut
- Bipartite matching
- Linear programming fundamentals
- P, NP, NP-hard, and NP-complete classes
- Approximation and randomized algorithms
